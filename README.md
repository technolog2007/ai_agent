# Local File Agent

Консольний Java-агент для безпечних операцій з файлами в одній дозволеній папці. Він надсилає текстовий запит локальній LLM через Ollama, отримує структуровану команду JSON і виконує її після валідації.

## Можливості

- перегляд файлів у дозволеній папці;
- читання вмісту файлу;
- переміщення одного файлу або файлів за шаблоном, наприклад `*.jpg`;
- створення директорій.

Доступ поза межами дозволеної папки блокується.

## Передумови

- Java 17;
- Maven 3.9 або новіший;
- запущений [Ollama](https://ollama.com/);
- модель `llama3.2:3b`.

Завантажити модель можна командою:

```powershell
ollama pull llama3.2:3b
```

## Налаштування робочої папки

Наразі шлях до папки, якою може керувати агент, задано у [App.java](src/main/java/com/example/App.java):

```java
Path allowedFolder = Path.of("C:\\Temp\\AgentTest");
```

Створіть цю папку перед запуском:

```powershell
New-Item -ItemType Directory -Force C:\Temp\AgentTest
```

Агент працює лише з файлами та підпапками всередині цієї директорії.

## Збірка і тести

```powershell
mvn test
```

Команда компілює проєкт і виконує всі JUnit 5 тести.

## Запуск

Спершу переконайтеся, що Ollama працює. За потреби запустіть його окремо:

```powershell
ollama serve
```

Потім у корені проєкту виконайте:

```powershell
mvn compile
java -cp target/classes com.example.App
```

Після появи запрошення `>` введіть запит, наприклад:

```text
покажи всі файли
```

Щоб завершити застосунок, введіть `exit`.
